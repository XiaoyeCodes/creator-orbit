# ORBIT · 自媒体终端

深色极简科幻风格的多平台内容工作台原型。使用原生 HTML、CSS、JavaScript，无需安装前端依赖。

## 启动

在此目录运行 `npm start`，浏览器打开 http://127.0.0.1:4173 。

## 功能

- 工作台：平台矩阵、演示指标、最近内容、发布队列。
- 内容管理：新建与编辑、草稿保存、排期、按状态及平台筛选、全文搜索、JSON 导出。
- 发布日历：切换月份、查看排期、编辑内容。
- 素材中心：四套 CSS 封面模板，可作为新内容的起点。
- 平台账号、数据洞察、工作台设置、消息通知。
- 响应式布局、键盘搜索快捷键、原生模态窗口、减少动态效果偏好。

所有账号、指标及初始内容均为演示数据。内容和设置保存在浏览器 localStorage，不包含平台授权、真实上传、数据同步或自动发布服务。示例日历基准为 2026-10-16。Google Fonts 无法访问时使用本地字体回退。

## 验证

`npm run check` 检查 JavaScript 语法。浏览器验证覆盖桌面和移动端布局、新建内容、保存持久化、搜索、筛选、日历、设置和导出。
