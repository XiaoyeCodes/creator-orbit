# ORBIT · 自媒体终端

深色极简科幻风格的多平台内容工作台。拾光百科模块已接入本机 Codex、文件和剪贴板；其他平台管理与数据仍是 UI 演示。使用原生 HTML、CSS、JavaScript 和 Node，无需安装前端依赖。

## 启动

双击 **启动工作台.cmd**，自动在后台启动服务并打开拾光百科页面。也可在此目录运行 `npm start`，浏览器打开 http://127.0.0.1:4173/#atlas 。

需要已安装 Codex 并通过 ChatGPT 登录，以及 Python 3.10+ / Pillow。本机已验证这些环境。其他机器可用 `ORBIT_CODEX_PATH` 和 `ORBIT_PYTHON_PATH` 指定程序位置。

## 拾光百科：生成到发布

“下一篇”实时读取 `data/主题/topics.md` 的首条 TODO，历史成果独立展示。点击 **编辑选题配置** 可直接修改完整 Markdown，包括标题、分类、状态和行序；保存后立即更新，原文件自动备份到 `data/主题/backups/`。也可点“用记事本打开”，外部保存后重新读取。将某条 TODO 改为“已生成”可跳过它；独立测试不会自动改变正式配置。

正式手动生成完成后可继续生成下一篇，没有每天一篇限制。未完成的正式任务优先恢复；运行中或存在未提交的正式任务时暂停配置保存，防止与正在生成的队列快照冲突。编辑版本冲突时不覆盖文件，浏览器草稿会保留。

1. 进入“拾光百科”，点击 **生成今日图文**。默认正式模式；独立测试模式不会推进正式主题队列。
2. Codex 后台读取 Skill、核实来源、用内置 GPT 生图并做逐页检查。无需 API Key，但会消耗登录账户的 Codex 额度。等待期间不要关闭本地服务。
3. 生成进度、封面、内页和文案在页面展示。失败会保留成果并提供“继续生成”，不跳到下一个主题。完成后才会开放发布准备。
4. 点击 **一键发布**：打开小红书创作页、素材文件夹、记事本文案、封面预览，并复制全部图片路径。
5. 在小红书点上传图片，在系统文件选择框按 Ctrl+V、回车，可一次选中全部图片。随后点工作台“复制标题”“复制正文与标签”，粘贴到平台；由你确认最终发布。

这里的“一键发布”是发布准备助手，不声称自动上传或代点最终发布。登录、验证码和平台提示由用户完成。图片路径和 Windows 文件列表一起写入剪贴板；路径中包含中文和空格也支持。

1086×1448 / 3:4 按用户确认作为提示词强要求，实际原生尺寸会展示，不做本地缩放、裁切、补字。其他 Skill 验收要求保持不变。

## 功能

- 工作台：平台矩阵、演示指标、最近内容、发布队列。
- 内容管理：新建与编辑、草稿保存、排期、按状态及平台筛选、全文搜索、JSON 导出。
- 发布日历：切换月份、查看排期、编辑内容。
- 素材中心：四套 CSS 封面模板，可作为新内容的起点。
- 平台账号、数据洞察、工作台设置、消息通知。
- 响应式布局、键盘搜索快捷键、原生模态窗口、减少动态效果偏好。

主工作台账号、指标及初始内容仍为演示数据，保存在浏览器 localStorage。**拾光百科的生成任务与素材真实保存在项目 `data/` 目录**。正式素材位于 `data/文案/Published-YYYY-M-D/<主题>/`，测试素材单独保存，过程、来源和日志在 `raw_generated/`。正式队列位于 `data/主题/topics.md`，首次按用户提供 Skill 快照初始化，此后不会覆盖。

在线静态站点只展示 UI，提供本机工作台入口；生成和桌面操作必须使用本机页面。Google Fonts 无法访问时使用本地字体回退。

## 验证

`npm run check` 检查 JavaScript 语法；`npm test` 检查任务、接口、隔离和发布准备逻辑；`python -m unittest discover -s tests -p test_adapter.py -v` 检查原 Skill 和尺寸适配。测试中的合成图片和记录仅为隔离结构验证，不是生成验收的证明。

浏览器检查还覆盖桌面/手机布局、图片预览、复制及发布引导。实现细节与边界见 `docs/integration.md`；实际测试结果见 `docs/verification.md`。
