# 拾光百科任务工作台 Implementation Plan

**Goal:** 实现用户已选定的方案 A：今日创作、作品库、选题库与统一作品详情。

**Architecture:** 沿用本机 Node 服务和 data/jobs，生成状态保持原语义，人工检查与发布记录独立持久化。选题表单通过现有 Markdown 版本校验、锁和备份机制修改原文件；不创建第二份作品台账。

**Tech Stack:** Vanilla JavaScript、CSS、Node HTTP、node:test、Playwright 浏览器验证。

### 视觉修订：深色编辑工作室

用户反馈初版留白过多、缺少设计感。保留方案 A 的信息架构，改造前端布局与视觉：取消固定 1500px 居中容器，压缩页头；创作面板与真实历史作品预览并排；图片风格改为带历史样图的选择卡；最近作品与待处理作品形成次级区域。使用炭黑、暖白、酸橙色及衬线选题标题建立层次。不添加虚构统计、进度或生成结果，不改生成与发布接口。复用现有交互回归，并补充 1920/2560 宽屏及风格选择、历史卡片入口检查。

用户已授权直接实施，在现有工作区完成，避免切换工作树导致正在使用的本机服务仍显示旧版。无需子代理、外部发布或真实生成测试。

### 1. 状态与选题操作
- 修改 lib/atlas.cjs、lib/topics.cjs、server.cjs。
- 增加 review、publication 接口；未就绪不得检查或标记发布，准备发布不自动标记成功，人工标记可撤销。
- 增加基于 revision 和行号的新增、编辑、优先生成、上下移动；保留原 Markdown 与备份。
- 同日同题再次生成必须使用新目录，已有任务恢复保持原目录。
- 在 tests/atlas.test.cjs、tests/topics.test.cjs 增加状态持久化、HTTP 访问保护、队列冲突及原文保留测试。

### 2. 页面结构
- 重构 dist/atlas.js，添加 dist/atlas-workspace.css；沿用原图预览、复制、发布准备与高级配置编辑器。
- 今日创作展示本次选题、设置、运行阶段、今日作品和全部待发布入口。
- 作品库支持搜索、生成日期、正式/测试和状态筛选；详情使用独立 job URL，返回保留筛选和滚动。
- 选题库提供表单编辑、排序、更换选题及已生成选题的已有作品入口。
- 后台轮询与当前查看作品分离，焦点、弹窗草稿和输入不被刷新覆盖。

### 3. 验证与交付
- npm run check、npm test、Python 工作流回归。
- 使用隔离模拟接口验证三页导航、生成后进入作品详情、检查与发布、筛选返回、选题操作、失败及空态。
- 在桌面与窄屏检查溢出、键盘焦点和截图；真实历史数据只读检查。
- 确认无运行中的生成任务后更新本机服务，保留全部原始数据。
- 更新 README 与验证记录，交付可打开的本机入口。
