# 选题配置编辑与下一篇读取

用户确认唯一配置源为项目的 `data/主题/topics.md`。顶部创作卡显示正在执行或待恢复的任务，否则显示该文件的第一条 TODO；浏览历史成果不能改变下一篇。

提供完整 Markdown 编辑窗口及记事本入口，显示实际文件路径、当前下一篇和待办数量。保存原文字节，不由界面重新生成配置；标题、分类、状态及行序均可修改。保存后即时刷新，回到浏览器也重新读取外部修改。

保存使用 SHA256 版本比较、与原 helper 相同的文件锁、原文件备份和原子替换。格式错误或外部版本变化保留草稿并拒绝覆盖。运行中或未提交的正式任务暂停配置保存，以保持原 Skill 的队列快照一致性。关闭未保存编辑器时提供保留编辑或明确放弃操作。

取消正式手动生成的每天一篇限制：完成提交后下一次点击生成下一条 TODO。独立测试继续不推进正式队列，相同配置同日可复用已完成的测试结果。

验证覆盖：解析与原 helper 的表头规则对应；保存、备份、版本冲突、锁；修改后的首条 TODO 被实际 prepare 读取；历史与下一篇分离；浏览器保存及草稿保护；四档响应式布局。使用临时配置测试，不改变用户正式选题。
