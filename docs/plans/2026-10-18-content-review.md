# 可选的独立内容复审与平台字数限制

用户要求核实小红书字数上限，图文完成后可开启或关闭 Codex 复审，发现错误自动修正，并给出真实测试结果。

普通图文上限统一为标题 20、正文 1000，依据官方学习中心公开索引；保守计入标签、空格、标点及规范化换行，前后端 Unicode 码点统计一致。长文入口单独看待。复审关闭不能绕过发布字数限制。

复审采用生成结束后的独立 Codex CLI 会话，复用 ChatGPT 登录，不使用图像 API。新增 reviewing 阶段，纳入锁、轮询、取消及重启恢复。新任务开关默认开启，按任务保存；已有完整作品可手动复审。修正前备份原文件；复审报告绑定最终文件摘要、逐页实际观察、来源和已修正问题。未通过则不提交选题，重试从复审阶段开始。

测试分层：隔离单元测试覆盖开关、边界、语义报告结构、失败/取消/恢复；浏览器验证开关记忆与提交、状态和六档布局；真实 Codex 对现有 11 张生成图的独立副本复审，在副本文案注入错误年代检验纠正能力。最终报告区分结构测试与真实模型运行，核对正式队列和原作品未变。
