# 小红书解读文案改进

用户反馈发布正文只列名词和一句概括，缺少专业解读。采用“完整底稿 → 面向读者的发布正文 → 图片”的现有流程，补充具体写作要求。仅增加字数无法保证信息量；不新增生成入口或改写历史成品。

新建任务持久化文案策略，启动提示词包含统一配置和格式说明。底稿不限发布篇幅；发布文案保留事实、解释与必要边界，在现有发布预算内用短段落阅读。原有 1–11 张、每对象一图、风格选择保持兼容。

验收要求真实复读记录、至少三处正文与底稿的原文证据，以及绑定最终文件的 SHA256。代码只验证可验证的结构和一致性，不把长度与关键词冒充语义质量。测试覆盖任务持久化、重试、策略透传、缺少记录、陈旧摘要、伪造引用、重复解读、篇幅预算和遗留策略。生成请求用隔离夹具，真实生图需另外观察效果。
