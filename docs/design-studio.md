# 偏爱日常设计所

在左侧「拾光百科」下进入「偏爱日常设计所」，或访问 `/#design-studio`。

这是以女性日常物品概念设计为内容的独立工作区，面向内容增长与品牌合作。现有 200 个选题：40 个包袋、30 个手机壳与随身小物、75 个女性衣物、15 个家居角落、40 个幸福感小物。每题有发布标题、正文、标签、设计档案和四张图的完整提示词，共800条。

第二辑新增 DS101–DS200，60个衣物设计与40个幸福感小物。点击「本次新增」可单独查看，或进入 `/#design-studio?collection=wardrobe-and-joy`。原100题及已保存修改继续保留。

题材的「首批 / 常青 / 探索」是编辑建议；并非已有流量数据或爆款承诺。先用首批题材观察真实收藏、评论和关注，再调整后续方向。

## 使用

1. 在选题库搜索场景或物品，按分类和优先级筛选。
2. 打开选题检查文案、设计细节与四份图片提示词。修改后保存；其他窗口已修改时，系统保留当前草稿并提示版本冲突。
3. 点击单篇生成。先生成主视觉，之后三张引用同一主视觉，分别展示细节、功能/空间和生活场景。
4. 在作品库预览实际图片、复制文案、保存原图或打开素材目录。生成失败或停止后，可在原目录继续。
5. 最终检查后自行到小红书发布。工作区不会自动上传或发布，也不会批量启动整个选题库。

书店通勤包导入自本聊天已经生成并逐张检查过的四张真实原图，导入后的原提示词与生成记录也保存在素材目录。其他选题完成的是内容方案，图片按需要逐篇生成。

## 内容与保存

- `config/design-studio/profile.json`：账号定位、类别、视觉方向。
- `config/design-studio/topics-a.json`、`topics-b.json`：第一辑100篇内容；`topics-c.json`、`topics-d.json`：新增60篇衣物；`topics-e.json`、`topics-f.json`：新增40篇小物。每题均有四页专属画面。
- `lib/design-studio-content.cjs`：将设计档案、品类规则和每页专属画面组合为完整提示词；不需要使用者自行替换占位符。
- `data/design-studio/edits/`：网页编辑的持久化版本与备份。
- `data/design-studio/works/`：每篇文案、提示词、四张原图和生成检查记录。
- `data/design-studio/jobs/`：任务状态。与拾光百科分开保存。

生成时保存不可变的稿件快照。之后编辑选题不会改写已有作品；「继续生成」继续该作品原稿。修改并保存新版本后，也可另开新作品，旧稿和原图保留。

网页可导出包含当前修改的 JSON：选「全部」导出完整库，选「本次新增」导出该100题。运行 `node scripts/export-design-studio.cjs` 可在 `data/design-studio/catalog-export/` 导出全部200题和本次新增100题的独立 JSON 与 Markdown 备份。

## 验证与边界

图片生成复用本机 ChatGPT 登录态和 Codex 内置生图。工作区一次处理一篇；停止、超时和异常退出会保留素材。生成依赖工具及账户额度，运行环境检查不能提前保证图像工具一定可用；实际不可用会留下失败原因。

完成状态需要四张可解码 PNG、3:4 比例、至少 768 像素宽、不同文件哈希、实际提示词与参考图记录，以及逐图检查记录。生成过程不得改变已确认文案与提示词。文件核验不能替代发布前对文字和设计合理性的检查。

图文清楚标注原创概念与 AI 辅助；衣物、包袋、手机壳没有实物打样和使用验证，家居图不是施工图或竣工案例。合作内容后续应以真实产品资料和品牌授权范围为准。

运行 `npm test` 检查接口、保存冲突、任务快照、单篇生成与恢复、图片验收；浏览器检查位于 `tests/design-studio.browser.cjs`。浏览器测试使用临时数据和受控生成替身，不调用生图、不改变真实作品。
