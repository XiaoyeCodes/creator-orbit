# 拾光百科图文生成

产出一篇完整系列：目录式封面、与主题结构匹配的内容页、中文小红书文案、可恢复的过程与核验记录。图片和文字均需真实生成与检验，不能把提示词文件当成成品。

## 运行前

1. 从用户指定的配置读取工作目录与主题队列；配置范例见 [config.example.json](config.example.json)。相对路径以配置文件所在目录解析，参考图相对本技能目录解析。不假定本机路径、账号、云盘权限或某个宿主可用。
2. 首次运行先核对实际工具：必须有内置 GPT 图片生成/编辑能力，能传入真实参考图片并取得成品供像素与视觉检查。工具名与参数以当前宿主提供的规范为准；仅有文本生成、外部生图 API 或只能读图不能传图，均不能满足本技能。缺少能力则保存规划并报告具体阻碍，不替换其他生图服务或索取 API Key。
3. 明确 test 或 production。测试使用独立复制的队列、台账和输出目录，绝不能修改原队列。生产使用用户选定的当前队列，随包快照只用于初始化/测试，不能覆盖累计进度。未提供当前队列且未明确测试时，请求该必要输入。
4. 读 [references/workflow.md](references/workflow.md)，读取最新主题与台账。先恢复生成中/未交付的本任务内容；完整且已交付内容无需等人工发布。正常只取第一条 `Status=TODO`，不跳题、不自由选题。开始前登记唯一 content_id、revision 和运行占用；并发冲突重新读取。

## 制作

- 读 [references/image-and-copy.md](references/image-and-copy.md) 和 [references/reference-catalog.md](references/reference-catalog.md)。本次运行实际查看全部七张图片，建立选图依据。每张内容页独立选一张最适合的底稿并真实传入图生图，可经判断重复使用。封面不受此限制。
- 先核实事实和完整正文，再把知识映射到所选底稿对应区域。优先一手来源，保存 URL、访问日期与支持的具体事实；参考图上的文字不是事实来源。
- 天然带数量的主题严格遵守数量，例如十大必须十张内容页加封面；无固定数量合理拆成四至八个核心知识点。不捏造“世界排名”或唯一分类标准。
- 所有图片必须直接生成为 `1086×1448`。禁止本地叠字、裁切、缩放或补图修复。提示词请求尺寸不等于实际满足；输出尺寸不符时用内置工具重新生成/编辑，再测量。工具无法满足时本篇失败。
- 标题/主图不得挤走信息。继承实际底稿结构与信息密度、图表区、底部完整介绍；不能仅模仿米黄配色。内容页底部通常安排120–180汉字的连贯科普，按底稿区域容量与可读性调整。
- 主目录只保留可发布成品：`00_封面_<主题>.png`、`01_<页主题>.png`…、`<主题>_小红书文案.md`。过程图、提示词、来源、逐页参考输入证明、质检放 `raw_generated/`。输出路径 `文案/Published-YYYY-M-D/<主题>/`，日期按 Asia/Shanghai；文件名需安全处理且保留完整主题的元数据。

## 校验、提交与交付

读 [references/quality-and-delivery.md](references/quality-and-delivery.md)。逐张检查真实像素和中文，成图与该页底稿并排对照；事实/比例/版式不合格就从原底稿重生，不在错误首稿上保留错误版式。自动检查只验证机器可判断项，不能替代看图与事实审查。

仅全部封面、内容图、文案、目录和所有核验通过，且成品已成功保存到用户选定的持久位置后，才将本主题唯一 TODO 改为已生成。使用版本/摘要校验与原子替换；任何失败保持 TODO，保留可恢复资产和阻碍。`已生成`不等于`已发布`。不修改初始已生成行或其他主题。

默认交付本地完整目录或压缩包与简短测试结果。云盘仅在用户明确配置目的地并授权后使用，详细协议见质量与交付参考；不要继承其他会话的账号授权。此技能绝不操作小红书登录、草稿或发布。

本技能本身不提供后台调度。仅当宿主支持定时任务且用户授权时配置时区与时段，调用示例见包外《使用说明.md》。没有宿主调度能力时只说明手动调用方法，不宣称定时已生效。
