# 图片提示词与文案规范

## 每张图片固定前缀

每次实际生图调用的 prompt 必须以 [prompt-prefix.txt](prompt-prefix.txt) 的三行原文开头。内容页紧接换行与 [edit-base-line.txt](edit-base-line.txt) 的完整原文，再换行加入本页内容。不要改写、缩短或在前面加说明。封面仅使用三行前缀，不附EDIT BASE句（封面不需要编辑底稿）。这两个文本文件是唯一规范源，构造实际prompt时读取其内容，不凭记忆重打。

接着写明本页新对象、对应原底稿各区域的核实内容、图表数据与完整底文。明确要求模型仅使用给定的已核实事实，禁止自行补充数字、工艺要求、机制、产区或健康功效；信息不足时减少内容而不是编造。不能在后半段加入“自由重排”、新的固定三栏比例或全宽正文等覆盖底稿的布局要求。不能把输入参考描述成 `REFERENCE ONLY` 或 `not an edit target`。形态不合适则改选更合适的参考，仅做必要局部调整。

每次必须实际传入选中的参考图文件；有 `referenced_image_paths` 时用准确本地路径。当前附带校验脚本验证 `referenced_image_paths` 的绝对路径机制。若宿主使用不同图像输入接口，必须先显式适配脚本与测试，再记录实际等效参数与附件标识；不能把真实工具参数伪装成现有字段来骗过校验。只有文件名或 LibraryID 文本不算图片输入。不要使用不支持参考输入的纯文生图代替。

## 视觉与信息

- 全套统一米黄旧纸、深棕细线、经典中文字体和可信的百科插画，但各页结构来自各自选中的底稿。
- 替换所有原主体与原文字，剔除手机黑边、状态栏、识图图标、红色讲解框、标章、水印。不得把参考知识未经核实继承。
- 主图细节引线要指到正确位置；文字清楚、手机放大可读，无乱码。不靠巨型标题、放大数字或装饰填版。
- 在原图表区域放有意义的结构图、机制图、流程、时间线、地图、分类树或比例比较。所有数值注明单位、适用范围和必要年代。图表比例需合理，没有可靠数值时不用虚构数据。
- 内容页底部保留连贯介绍：对象是什么、特征/机制、背景和意义，通常120–180汉字。底稿多区域时在对应区内组织，不强行改成全宽正文；不是几个标签或几十字短卡。
- 科学复原、工艺示意和非作品原图需适当标注“AI示意”或更准确的说明，不冒充实物照片、真实地图测绘或作品原作。

## 封面

独立目录式博物馆图鉴/展板/古地图目录；中央清晰主题标题，周围代表对象、地点或分类有中文标签与简释。让人看到本期范围，不用抽象海报。封面无须内容页参考输入，但同样严格像素与事实检查。

## 文案

完整小红书文案包含标题、正文、标签。开头用有据可查的抓人事实或反常识问题，正文用尺度感、对比、地理/历史背景串成故事；结尾用真正与主题相关的问题引导评论。口语自然，不写成教材或百科词条，不承诺“爆火”。

禁止词：首先、其次、再次、最后、总的来说、综上所述。正文不得推广未经证实的健康功效。3个核心标签加5–10个相关标签；标签不得无关蹭热度。标签总数8–13个，无重复，文案中的数字要与图中一致。保存来源备查但避免在发布文案中堆内部质检记录。
