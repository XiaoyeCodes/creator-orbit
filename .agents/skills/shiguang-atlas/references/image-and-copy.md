# 图片提示词与文案规范

## 每张图片固定前缀

每次实际生图调用的 prompt 必须以 [prompt-prefix.txt](prompt-prefix.txt) 的三行原文开头。内容页紧接换行与 [edit-base-line.txt](edit-base-line.txt) 的完整原文，再换行加入本页内容。不要改写、缩短或在前面加说明。封面仅使用三行前缀，不附EDIT BASE句（封面不需要编辑底稿）。这两个文本文件是唯一规范源，构造实际prompt时读取其内容，不凭记忆重打。

前缀文字、标点与行序必须一致；仅 Windows CRLF 与 LF 换行在前缀检查时等价。prepare 输出的 required-*.txt 使用 LF。已有实际调用输入保留原样，不为通过检查修改历史 prompt、actual_input 或调用证据；三者仍须严格一致。

接着写明本页新对象、对应原底稿各区域的核实内容、图表数据与已单独编写的百科介绍。将【图中可见文字】与【绘制与核查要求，仅供执行、不渲染】分开；前者只包含最终标题、标签、图表说明和介绍正文，后者放构图、视觉约束与检查要求，分隔标记也不渲染。完整底稿用于核实与选材，不将含有绘图备注的整段底稿直接当成图中文字。明确要求模型仅使用给定的已核实事实，禁止自行补充数字、工艺要求、机制、产区或健康功效；信息不足时减少内容而不是编造。不能在后半段加入“自由重排”、新的固定三栏比例或全宽正文等覆盖底稿的布局要求。不能把输入参考描述成 `REFERENCE ONLY` 或 `not an edit target`。形态不合适则改选更合适的参考，仅做必要局部调整。

每次必须实际传入选中的参考图文件；有 `referenced_image_paths` 时用准确本地路径。当前附带校验脚本验证 `referenced_image_paths` 的绝对路径机制。若宿主使用不同图像输入接口，必须先显式适配脚本与测试，再记录实际等效参数与附件标识；不能把真实工具参数伪装成现有字段来骗过校验。只有文件名或 LibraryID 文本不算图片输入。不要使用不支持参考输入的纯文生图代替。

## 视觉与信息

- 全套统一米黄旧纸、深棕细线、经典中文字体和可信的百科插画，但各页结构来自各自选中的底稿。
- 替换所有原主体与原文字，剔除手机黑边、状态栏、识图图标、红色讲解框、标章、水印。不得把参考知识未经核实继承。
- 主图细节引线要指到正确位置；文字清楚、手机放大可读，无乱码。不靠巨型标题、放大数字或装饰填版。
- 在原图表区域放有意义的结构图、机制图、流程、时间线、地图、分类树或比例比较。所有数值注明单位、适用范围和必要年代。图表比例需合理，没有可靠数值时不用虚构数据。
- 内容页底部采用百科条目式科普：客观、中性、易懂，以第三人称直接介绍对象是什么，再自然展开与其相关的背景、特征、机制或影响。用自己的话概括已核实资料，借鉴百科介绍风格但不照抄原文。通常120–180汉字，按阅读空间调整；不强套相同栏目或凑字数。底稿多区域时在对应区内组织，不强行改成全宽正文。
- 讲清楚就结束，不给每页追加纠偏、提醒或免责声明式结尾。图片独立选取底稿中的具体知识，不继承其论证收尾，也不套用发布短文的反差与反驳示例。生图前连读整组末句：不反驳前文未提出的误解，不重复已经说明的差异，不换成同义尾注或另加总结凑结尾。必要限定放在相关事实旁；有实质信息的正常否定句仍可使用，按语义编辑，不设禁词表。
- 图中文字稿只保存读者应看到的内容。绘图要求、编辑提醒和质检说明另存内部文件；逐句按含义识别，不设关键词黑名单。必要的范围、争议和不确定性自然融入相关事实，不能为去掉注解腔而删除真实限定。发布短文与图中介绍分别编写，以下“小红书文案”的叙事要求不覆盖图片的百科语体。
- 科学复原、工艺示意和非作品原图需适当标注“AI示意”或更准确的说明，不冒充实物照片、真实地图测绘或作品原作。

## 封面

独立目录式博物馆图鉴/展板/古地图目录；中央清晰主题标题，周围代表对象、地点或分类有中文标签与简释。让人看到本期范围，不用抽象海报。封面无须内容页参考输入，但同样严格像素与事实检查。

## 文案

完整小红书文案包含标题、正文、标签。先选一个值得回答的问题或有用的比较角度，开头用有据可查的具体事实、困惑或差异；正文用案例逐步推进解释，结尾回扣主线，可自然结束，不强制提问。口语自然，不写成教材或百科词条，不承诺“爆火”。完整底稿和整组图片覆盖选题对象；发布短文可以选择重点案例，不强制逐项摘要，仍须独立回答主问题并兑现标题承诺。宿主提供文案策略时优先按对应版本的生成与复审规则执行。

不设置词语黑名单；根据上下文判断表达质量，正常叙述和引用均可自由使用。正文不得推广未经证实的健康功效。3个核心标签加5–10个相关标签；标签不得无关蹭热度。标签总数8–13个，无重复，文案中的数字要与图中一致。保存来源备查但避免在发布文案中堆内部质检记录。
