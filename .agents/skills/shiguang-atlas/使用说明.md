# 拾光百科图文 Skill 使用说明

这份技能把“从主题队列选题→真实参考图生图→完整文案→逐页校验→保存并更新状态”封装给其他Codex使用。默认仅生成素材；不会登录小红书、存草稿或发布，也不包含账号密码、API Key、固定云盘目标或本会话权限。

## 安装

1. 解压后，把完整 `shiguang-atlas` 文件夹放到目标Codex的技能目录，保留其中的7张参考图片与子目录。
2. 当前Codex支持用户级 `$HOME/.agents/skills/shiguang-atlas` 或项目级 `.agents/skills/shiguang-atlas`。Windows用户级示例：`%USERPROFILE%\.agents\skills\shiguang-atlas`。具体以目标宿主的[官方技能文档](https://learn.chatgpt.com/docs/build-skills)为准；若应用提供专用导入入口，导入完整目录。
3. 在目标Codex重新加载技能或开启新会话，确认能找到 `shiguang-atlas`。
4. 复制config.example.json到自己的工作目录，填入主题队列与输出路径。相对路径按配置所在目录解释，参考图从技能包读取。校验脚本需要Python 3.10或更新版本与Pillow。仅在目标环境缺少Pillow时，按该环境的软件安装权限运行 `python -m pip install Pillow`（官方PyPI）。Pillow仅用于解码与读取像素/尺寸，不修图、不生成用户成品。

这不是独立生图软件。目标Codex须实际提供内置GPT图像生成/编辑、真实参考图片输入、文件读取保存与查看图片的能力；仅安装技能不会给原本没有生图能力的宿主新增能力，也不保证任意模型能准确输出指定尺寸。缺能力时应该明确失败，不能用外部API或占位图冒充。

## 第一次先测试

把自己的最新主题表复制到测试工作区。随包 `shiguang-atlas/assets/topics.snapshot.md` 是制作时的主题表副本，只能作测试/初始化参考；不要用它覆盖已经更新过的生产表。

给Codex发送：

> 使用 $shiguang-atlas。读取我指定的config.json，以test模式在独立测试目录执行一次：复制主题队列，选择副本第一条TODO，实际生成完整封面、全部内容图和文案。每张内容图都真实传入随包七图中选定的编辑底稿。逐张检查实际1086×1448、中文、事实和参考版面，输出成品与测试报告。不修改生产队列、台账、定时任务或云盘，不发布。

确认报告不是只检查文件名：应列出实际图数、像素、逐页参考、事实来源、版式与文字检查，以及未通过项。输出尺寸不符时不能本地缩放修复。

## 正式单次使用

> 使用 $shiguang-atlas，按我指定的config.json以production模式生成一篇。读取当前主题表首条TODO，完成真实图生图、文案和全部质检后保存到配置的持久工作目录；成功才把该主题改为已生成。只交付素材，由我自己发布。

## 定时调用

技能文件本身不含常驻程序或调度服务。只有目标宿主支持定时任务且能在任务里调用内置生图时，才可以配置北京时间每天07:00、12:00、19:00三次。电脑本地任务是否要求开机、云任务能否使用图像工具，必须在目标宿主实际核实。

可给支持的宿主发送：

> 请为 $shiguang-atlas 配置三个素材生成任务，时区Asia/Shanghai，每天07:00、12:00、19:00分别运行。每次读取指定config.json和最新主题表，只生成首条TODO的一篇；每时段最多一篇，恢复进行中的任务，不追补旧名额。仅生成、核验和交付，不操作小红书。成功通知主题和素材位置；失败保留TODO并报告具体阻碍。请回读确认实际任务设置后再告知已启用。

如使用云端宿主，必须配置它能持久访问的队列、状态与图片位置；Windows本地路径不会自动出现在另一台云电脑上。云盘上传是可选功能，需要目标宿主重新连接并由你授权目标私有目录。不要把私有下载链接当作永久同步地址。

## 包中内容

- shiguang-atlas/SKILL.md：技能入口
- references：参考图选择、图文要求、队列/恢复、质量与可选交付规范
- assets/reference-images：七张实际图片底稿
- config.example.json：相对路径配置范例
- scripts：确定性准备、验证和安全提交助手
- 测试报告与样图（若本次验收产出）：以实际附带结果为准，不能从本说明推断已经全部测试通过
